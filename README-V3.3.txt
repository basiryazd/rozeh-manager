نسخه نهایی V3.3 — سامانه مدیریت روضه حسینیه عسکریه

آیکون اختصاصی حسینیه عسکریه برای iPhone/PWA اضافه شده است.

روش نصب روی آیفون:
1) کل پوشه برنامه را روی یک هاست HTTPS قرار دهید.
2) آدرس سایت را در Safari آیفون باز کنید.
3) Share را بزنید.
4) Add to Home Screen را انتخاب کنید.
5) Add را بزنید.
بعد از آن آیکون «مدیریت روضه» روی صفحه اصلی آیفون نمایش داده می‌شود.

نکته: باز کردن مستقیم فایل ZIP یا index.html از Files آیفون، نصب PWA واقعی ایجاد نمی‌کند؛ برنامه باید از HTTPS سرو شود.
